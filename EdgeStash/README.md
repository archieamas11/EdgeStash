# EdgeStash

A small, independent macOS menu bar utility for keeping windows at a screen edge. No account, payment, license check, network connection, or third-party runtime.

## Build and run

Requires macOS 13+ and Apple's Swift tools (Xcode Command Line Tools).

```sh
swift run EdgeStashChecks
sh scripts/check-settings.sh
sh scripts/check-runtime.sh
sh scripts/build-app.sh
open dist/EdgeStash.app
```

Move `dist/EdgeStash.app` to Applications if desired **before** granting Accessibility access. Open the menu bar icon → Enable Accessibility, then enable **EdgeStash** in System Settings → Privacy & Security → Accessibility. Return to your working window. A rebuilt/ad-hoc signed app can need removal and re-adding in Accessibility settings.

The build script creates an ad-hoc signed app for the current Mac's architecture. It verifies the linked SDK version so newer macOS releases enable their native appearance while retaining the macOS 13 deployment minimum. The current Swift 6.4 SwiftBuild engine records the deployment version as the linked SDK, so this script temporarily selects SwiftPM’s native build engine; remove that override when the upstream metadata issue is fixed. It is not notarized or an App Store distribution.

If macOS shows access enabled after an update but stashing still fails, quit EdgeStash normally, remove its old entry with the minus/Remove button in the privacy pane, then use Add to select this exact `dist/EdgeStash.app` and enable it before relaunching. Merely toggling the stale entry may leave its old signing requirement in place. On newer macOS versions, this pane may be named **Device Control and Data Access**.

## Use

| Shortcut | Action |
| --- | --- |
| Control–Option–Command–← / → / ↑ / ↓ | Stash focused window on that edge; repeat on the same window to restore |
| Control–Option–Command–U | Restore the focused stashed window |
| Control–Option–Command–Shift–U | Restore every stashed window |
| Control–Option–Command–J | Cycle the most recently revealed app stack |

Open **Settings…** from the menu bar (or reopen the app) to edit Stash, Shortcuts, and Appearance. Settings uses a native macOS sidebar, grouped forms, system accent color, and a live indicator preview. Hover over a feature’s info icon for details; click or activate it with the keyboard to keep the popover open, then press Escape or click outside to dismiss. The window remembers its size and position. Standard controls adapt to the current macOS appearance from the macOS 13 minimum; native Liquid Glass appears where supported. Every shortcut can be recorded, cleared, or reset; duplicate and bare-key combinations are rejected. Shortcuts are suspended while EdgeStash settings or its color picker is active.

Hover or click an app indicator to reveal, focus, and raise its window above other normal app windows. Turn **Open on hover** off in Settings → Stash for click-only opening. Modifier-drag reorders or repositions notes according to the selected layout mode. Reveals sit beside their stash edge and align with the indicator’s center, clamped inside the usable screen bounds so the window does not extend past the menu bar or Dock. The app's indicator disappears while a window in that app's stack is open and returns after it hides; its slot remains reserved so other notes stay still. After hiding the window, its note slides back from the edge; the animation setting and Reduce Motion apply to both window and indicator motion. In cursor-leaves mode, moving outside the revealed window hides it after the configured delay. Hovering another stash indicator keeps open windows stable, including while that indicator opens its window. Moving into ordinary desktop content resumes normal dismissal. In **Only when I press Escape** mode, pointer/focus changes leave it open. Outside clicks are intercepted before another app can activate, avoiding the click-driven focus flash. The pinned app, its dialogs, stash controls, menu bar, Dock and system recovery controls remain interactive. Other focus changes retain the raise/refocus fallback. Plain Escape dismisses the most recently revealed stash. EdgeStash Settings retains focus while you configure the app. Settings retains its normal Escape behavior. App/system floating panels can remain above a raised window under macOS window-ordering rules. Escape never invokes Close or Quit. A **Hide … to Stash** menu command provides a mouse-accessible alternative.

Reopening prepares the hidden window beside its current indicator before starting the slide. Left/right stashes slide horizontally; top/bottom stashes slide vertically, without travelling from an old note position or a sideways corner fallback. On macOS 14 or later, enable **Settings → Stash → Screen Recording…** for a full top-edge slide: a temporary image of that individual window slides into or out of place, then the real window takes over. The image is clipped to its original display and never accepts clicks. Capture is one image per transition, with no audio, files, uploads, or idle capture; the image is discarded at completion or cancellation. Restore, Escape, sleep, and Space changes cancel interrupted image slides. If access is absent, capture fails or times out, or the window is unavailable/protected, it opens directly. Other edges continue moving the real window. The motion setting and Reduce Motion apply to both paths.

Dragging or otherwise moving a revealed window automatically unstashes it, leaving it exactly where you moved it. Resizing keeps it stashed and remembers the new dimensions, including resizes from the top or left. Permanent **Unstash** uses its pre-stash position and latest size. Small movement tolerances ignore Accessibility rounding, and programmatic animation frames are excluded from move detection.

**Stack windows from the same app** groups windows by app, edge, display, and desktop. The indicator shows an app icon and window count; clicking cycles that app's windows. Control–Option–Command–J cycles the most recently revealed app stack. With stacking enabled, only one window in each app stack is revealed at a time; opening another app no longer replaces the first app’s window. Indicators and reveal actions stay on their originating desktop/Space. A separate transparent desktop marker retains membership even while indicators are hidden; returning to the Space repairs the indicators after Mission Control settles. They do not follow you to another Space.

Appearance provides a live preview, indicator thickness (0–48 points), full-edge height by default, or an opt-in custom height (24–320 points, stored default **48**), inward corner radius (0–24 points), gap (0–48 points), **Show app icon**, app icon size (16–64 points), **Liquid Glass indicators**, **Use app brand color**, a default color, and per-app color overrides. The icon sits inside a compact sticky note and shrinks to fit the chosen height. Only the two inward corners are rounded; the outside of the bar sits square against the display edge. Liquid Glass is untinted and uses the native macOS 26+ material, with a frosted-glass fallback on macOS 13–15. At thickness 0 the bar disappears, leaving only the icon; with icons hidden, an invisible 1-point edge target retains hover access. Color settings are retained and reappear when glass mode is turned off. Brand color is estimated from the dominant saturated color in the app's icon; neutral icons use the default. A per-app override takes priority over either automatic choice.

Hold the selected **Drag modifier** before pointing at a note, then drag along its edge. Full-edge mode swaps slots on release; custom-height mode uses magnetic placement with collision avoidance. Hover must leave a note’s activation region before it can rearm. Settings → Appearance explains both modes and provides numeric inputs beside the sliders.

Mouse movement drives coalesced hover checks. When idle with no stashes, window-monitoring timers, mouse monitors, focus observers, and Escape interception are removed. Hidden-only maintenance runs at 0.5-second intervals; revealed geometry is checked at most every 0.12 seconds and reused for pointer dismissal. Process-liveness checks run once every two seconds instead of on every pointer tick. Before sleep, animations settle and revealed stashes hide; on wake, shortcut/event-tap registration and desktop indicators reconcile after displays settle. Entries on disconnected displays restore onto a connected display.

Stashing preserves each window's pre-stash position and remembers observed size changes. Where macOS clamps top/bottom movement and leaves visible content, EdgeStash tries a safe sideways corner, reading back the real frame and checking every display. If no safe corner works, it minimizes that individual window and keeps its logical edge tab. The original restore frame and logical edge remain unchanged. The shipped Rectangle Pro 3.99 warning also recommends corner hiding; see [focused evidence](docs/rectangle-top-bottom.md). The corner-selection and minimization mechanisms here are independently written. It never hides an entire app. An edge is rejected if it joins another monitor or its hidden window would overlap another display across a gap. Top notes default to a free area beside the camera notch at the physical screen edge. Manually moved top notes clamp sideways around the notch; oversized notes shrink only when needed to fit beside it. Automatic stacks stay packed within that safe area, and saved manual positions use the actual clamped location. Bottom notes stay on the physical bottom edge beside the Dock. Default stacks pack into a free side; Shift-dragging across the Dock clamps sideways, shrinking long notes if needed. Dock bounds come from the first and last Accessibility items, with a small clearance, rather than the Dock’s screen-sized backing window. Dock checks run only while bottom stashes exist, at most twice per second through the existing activity loop. Left/right notes retain usable screen bounds. If the Dock consumes the entire edge, only a one-point side target can remain until space is available. Notes retain their window level above ordinary app windows and system bars. Real foreign app windows remain subject to macOS window-level rules; Accessibility cannot guarantee they cover the menu bar or Dock. Windows in native full screen are rejected.

Quit normally to restore every managed window. Changing the monitor arrangement also restores windows to a connected display. A failed restore keeps its entry and prevents normal quit so the restore action remains available. Errors appear in the menu and play the system error sound.

## Recovery and privacy

Before moving a window, EdgeStash atomically records its process ID, process launch time, title, and original frame in `~/Library/Application Support/EdgeStash/recovery.json` (owner-only file permissions). The recorded restore size is updated after resizing a revealed window. Window titles stay on this Mac. With Screen Recording access enabled, top-edge transitions capture one image of the target window in memory only on macOS 14 or later; no image files or audio are recorded. Capture never runs while idle, and images are discarded when the transition finishes or is cancelled. Settings requests Screen Recording access only through its explicit button; without access, stashing still works and top windows open directly. Escape mode installs a keyboard event tap to handle only plain Escape while a stash is revealed; keyboard text is not recorded. Pointer monitors inspect event type and pointer position only and are removed while no windows are stashed. macOS must allow the event tap; a permission failure is shown in the menu, and the menu’s Hide … to Stash and Restore commands remain available.

On the next launch with Accessibility access, EdgeStash attempts to restore journaled windows. A process must have the same launch time and a unique matching window title; when AppKit omits the launch date (including Finder on some systems), EdgeStash uses the kernel’s process start time for stashing, maintenance, restoration, and recovery; it does not guess between duplicate titles. Changed titles, duplicate titles, inaccessible windows, and windows in other Spaces may require manual recovery: unminimize using the Dock or the app's Window menu, then move the window using macOS or another window manager. Original geometry stays in the journal for unresolved records. Force-quitting bypasses orderly restoration.

## Scope and verification

The implementation uses public Accessibility APIs, AppKit, Core Graphics event taps, and Carbon's global hotkey API. Settings are stored locally in UserDefaults (`EdgeStash.preferences.v1`). It is independently written; evidence describing Rectangle Pro is in `docs/rectangle-stash.md` when present.

Geometry and preferences self-checks cover four-edge reveal anchoring, animation interpolation, multiple-monitor coordinates, shared-edge rejection, tab placement, restoration bounds, saved settings and shortcut conflicts. A native settings smoke check constructs and resizes the actual window to catch runtime layout exceptions and collapsed content. The release build verifies compilation and bundle signing. Cross-application Accessibility behavior must be checked interactively; automated tests do not establish that all apps accept window moves.

Intentionally omitted: drag-to-stash, app-focus auto-reveal, bulk stash commands, and automatic launch at login. See `docs/verification.md` for tested behavior and remaining runtime checks.

When updating a running copy, quit EdgeStash normally to restore its windows, then reopen the rebuilt app. Do not force quit while windows are stashed. A new ad-hoc signature may require re-adding Accessibility access.

Indicator bar thickness stays independent of app icons, including 0 or 1 pt. Appearance → App icons → **App icon offset** moves the icon from −64 to +64 pt (negative moves toward the display edge; content beyond the edge is clipped) so it floats beyond the bar without widening it. This works on every edge in color and glass modes.


### Indicator layout (1.14)

**Use full edge** is enabled by default, including when upgrading existing settings. A single note fills the available edge; multiple notes divide it equally after subtracting the Gap. Top and bottom distribute notes across both available stretches beside the notch or Dock. A single note chooses the safe side nearest its saved anchor or window position. Revealed stashes keep their reserved slot. Hold the chosen **Drag modifier** (Shift by default; Option, Control or Command are available) and drag onto another slot to swap on release. Turn Use full edge off to explicitly choose the stored custom Height and use magnetic positioning. Both modes enforce gaps and prevent note/icon overlap; crowded edges shrink notes and icons to fit. Dragging keeps the notes stable until release, then applies the collision-free layout. Every slider now has a numeric field for exact values; inputs use the same validation and limits as sliders. Icon offset and sizing remain independent of bar thickness on all four edges; negative offsets beyond the physical edge intentionally clip.

Custom-height values and saved anchors are retained when toggling modes.

Wake recovery reconciles markers and indicator ordering three times while the desktop/display settles, accepts repeated screen/system wake notifications, and cancels pending recovery if sleep resumes. Display restoration waits for the final wake attempt rather than reacting to transient missing-display metadata.

In “When the cursor leaves” dismissal mode, an outside left/right/middle click hides revealed windows immediately, regardless of hide delay. Clicking a stash indicator keeps existing reveals stable while selecting another stash. Indicators use native macOS window shadows.
